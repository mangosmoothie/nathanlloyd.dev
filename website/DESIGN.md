# DESIGN.md – nathanlloyd.dev

## Overview
The homepage reads as a file. A numbered index, a file header with the portrait, a four-cell record, then work, practice and employment as ruled rows.

## Visual Identity
- Cool gray sheet, black rules, one steel-blue signal color for indexes and links.
- IBM Plex Sans for reading, IBM Plex Mono for file numbers, labels and status.
- No rounded cards, no gradients, no third-party CDNs. The portrait is grayscale.

## Sections
- File header and engagement brief
- Record (20+, 144M+, 10 TB, 3×)
- Work, numbered 01–04, plus this site as record 05
- Practice, a six-cell ruled grid
- Employment table, honors, education, and a short personal note
- Inquiry: Calendly, email, LinkedIn and the contact form
